# 清屏 1.1.0

- 修正坐标手势的结果判断：等待完成回调；拒绝、取消或超时不计入完成操作数。
- 查询提交前占位，任务取消或失败后释放；合并后续查询，保留忙碌时到达的延迟规则请求。
- 动作前重新核对屏幕、匹配开关、15秒窗口、当前窗口和目标规则，避免使用过期节点坐标。
- 保留无操作前置规则与后续规则的执行链。
- 修复后台冷启动时规则晚于首个页面事件加载的问题；规则就绪后刷新当前页面，不要求先打开清屏，也不延长15秒开屏窗口。
- 使用线程独立的日期格式器；工作模式页恢复前台时刷新权限；事件日志无数据时等待，减少空闲轮询。
- 新增独立复查统计：原出口消失、仍存在、未知、跨应用。最多采样两次，不自动重复点击，也不根据跨应用结果强行返回。
- 新增默认关闭的开机／解锁有限恢复。需要允许自启动及一次授予写入安全设置权限；主动关闭后暂停恢复，不使用定时闹钟。

与1.0.0保持相同包名和签名，可覆盖升级，保留原有订阅、设置和累计数据。旧累计依然表示操作结果，不会重新解释为确认关闭广告。

原出口消失仍不等于广告请求被拦截。强行停止后不保证自动恢复；小米13实际耗电和一键清理后的存活情况需要真机验证。

基于GKD v1.12.1二次开发，继续保留GPL-3.0许可证和上游归属。优化思路参考gkd_pure、GKD-Plus、GKD特调版与Bypass Ads，未整体替换上游引擎。
