# 清屏 1.1.0 实施计划

依据已确认的 Fork 审查，沿用 Kotlin、无障碍与原订阅引擎，逐项实现修复，保留包名和签名。

约束：15秒开屏窗口、熄屏不执行、跳转防护按App授权、保留现有累计数据。无需Root；不新增精确闹钟、持续OCR、AI服务或自动跨App返回。恢复需用户开关、有效安全设置权限和系统广播支持。

## 1. 动作与调度

- [x] 为手势拒绝、取消、完成、超时及重复回调建立回归测试，再实现完成回调等待。
- [x] 为快速提交、执行前取消、旧任务释放、唯一后续任务建立测试，再接入查询任务协调器。
- [x] 在动作前验证坐标、矩形、可见性、所属App及页面时效；保留明确声明的合法偏移坐标。

## 2. 空闲开销与正确性

- [x] 多线程格式化测试后替换共享格式器。
- [x] 权限页进入和恢复前台时刷新，停止每秒轮询。
- [x] 事件日志无数据时挂起，批量写入并在退出时刷尾。

## 3. 有限结果复查

- [x] 建立存在／不存在／不可验证、页面空白、规则丢失和外部跳转的判定测试。
- [x] 成功操作后使用独立新鲜节点上下文复查原规则；最多两次采样，不自动重放动作。
- [x] 累计操作数继续表示操作完成，新增分开的验证结果累计，旧计数不重解释。未知不能计入确认关闭。

## 4. 有限恢复

- [x] 测试关闭意愿、权限缺失、其他服务变化和有限重试。
- [x] 增加默认关闭的恢复开关；开机、解锁和包更新后有限尝试，统一写入入口、每次重新读取设置、不摘除其他服务。
- [x] 应用内关闭无障碍或关闭恢复时，待执行恢复停止；系统设置主动关闭的意图无法可靠区分，不承诺自动恢复所有场景。

## 5. 验证与成品

- [x] JVM回归、设备行为测试、正式版构建、lint和独立代码审查。
- [x] 模拟器验证规则匹配、错误统计不增加、熄屏停止和升级保留数据。
- [x] 复用签名打包，更新使用说明与校验；小米13耗电、清后台存活仍需真机验证。
