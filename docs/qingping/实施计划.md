# 清屏实施计划

目标：基于固定的 GKD v1.12.1 提交构建独立应用，交付 APK、源码和可复核验证结果。

架构：保留上游无障碍规则引擎及设置页面，增加清屏的保守规则准入和持久统计；默认关闭通知服务与点击提示，隐藏最近任务卡片。无需 Root 或 Shizuku。

约束：成功动作次数不能称为已证实广告消失；不承诺强行停止后运行；不伪造小米实测或耗电结果。

## 任务

- [x] 构建基线：固定 5a00f844989471458e4cf4601acb3f4710438f9a；检查现有工具，补齐构建所需 SDK；保存基线构建结果。
- [x] 应用身份与默认设置：修改 applicationId、名称、版本及独立签名；关闭官方自动覆盖更新，默认隐藏最近任务、关闭常驻通知和点击提示；保留上游版权。
- [x] 规则准入：增加可单测的 QingpingPolicy，仅允许开屏／广告类规则；广告退出规则按应用显式启用；其他自动点击默认不执行。对设置与准入边界先写失败测试，再实现。
- [x] 持久统计：为成功执行动作增加独立累计表，按应用和类型聚合；记录在上游动作成功分支中，避免历史日志清理损失累计数；测试失败不计数、按类型聚合与保存行为。
- [x] 页面接入：新增首页清屏卡片，展示运行边界和本地统计，提供规则导入入口及按应用跳转防护开关；复用上游暂停与设置入口。
- [x] 验证交付：运行 JVM 测试、安卓编译及 lint；模拟器测试授权、规则点击、统计、最近任务和服务生命周期；签名验证并计算 APK 哈希，保留真机待验证项。

## 审查重点

1. 常规页面不能被当作广告返回，只有明确规则与按应用开关允许时执行。
2. 自动更新不得把清屏覆盖为官方 GKD，应用 ID 不与 GKD 冲突。
3. 日志清理、重启、重复事件不能破坏统计口径。
4. 不额外创建后台轮询、唤醒锁或常驻前台服务。
5. 编译和模拟器结果与小米 13 真机结果分开报告。
